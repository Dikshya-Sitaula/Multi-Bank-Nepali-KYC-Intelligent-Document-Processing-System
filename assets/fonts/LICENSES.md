All fonts were downloaded from the Google Fonts repository (github.com/google/fonts, `ofl/`)
and are licensed under the SIL Open Font License 1.1, which permits use, embedding and
redistribution. They are used only to render fictional synthetic handwriting.

| File | Family | Scripts | Licence |
|---|---|---|---|
| Kalam-Light.ttf, Kalam-Regular.ttf, Kalam-Bold.ttf | Kalam (Indian Type Foundry) | Devanagari + Latin | OFL 1.1 |
| PatrickHand-Regular.ttf | Patrick Hand | Latin | OFL 1.1 |
| Caveat[wght].ttf | Caveat | Latin | OFL 1.1 |
| GochiHand-Regular.ttf | Gochi Hand | Latin | OFL 1.1 |

Limitation: Kalam is the only handwriting-style Devanagari font here, so synthetic Nepali
handwriting has little writer variety. Extra open fonts can be dropped into this folder.
